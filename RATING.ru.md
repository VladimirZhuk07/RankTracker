# Система рейтинга игроков

В этом документе описывается, как рассчитываются рейтинги игроков в RankTracker.
Вся логика находится в [`src/lib/calculations.ts`](src/lib/calculations.ts) и
[`src/hooks/use-ranked-users.ts`](src/hooks/use-ranked-users.ts).

---

## Обзор

Рейтинг каждого игрока — это число по шкале **от 0 до 100**. Он отражает две вещи:

1. **Результативность в матчах** — убийства, смерти и урон с поправкой на исход матча (победа/поражение/ничья).
2. **Нормализация** — очки масштабируются относительно фиксированного теоретического потолка, чтобы число было понятным.

---

## Шаг 1 — Модификатор победы/поражения/ничьей

К каждому матчу применяется модификатор для убийств и урона (но **не** для смертей — умирать одинаково плохо вне зависимости от исхода матча):

```
if sessionHasWinner:
  modifier = won ? 1.1 : 0.9
else:
  modifier = 1.0
```

- **Победа** (W): увеличивает вклад убийств и урона игрока на 10%.
- **Поражение** (L): уменьшает вклад убийств и урона игрока на 10%.
- **Ничья / нейтральный матч** (N): не даёт ни бонуса, ни штрафа.

Сессия считается **нейтральной**, если ни у одного игрока в этой сессии нет `won = true` (как правило, это матчи с равным количеством раундов у команд и без победителя). В нейтральной сессии все игроки получают `modifier = 1.0`.

Смерти никогда не модифицируются — накопление смертей в проигрышном или нейтральном матче не прощается.

---

## Шаг 2 — Накопление статистики

Каждый матч добавляется к накопленным итогам игрока:

```
effectiveKills  += kills  × modifier
effectiveDeaths += deaths
effectiveDamage += damage × modifier
totalMaps       += 1
```

После суммирования всех матчей рассчитываются средние показатели за матч:

```
kdRatio       = effectiveKills / effectiveDeaths   (= effectiveKills если смертей нет)
averageDamage = effectiveDamage / totalMaps
```

---

## Шаг 3 — Сырой рейтинг

Сырой рейтинг объединяет K/D и средний урон по той же формуле:

```
rawRating = kdRatio × 2 + averageDamage / 100
```

K/D имеет вдвое больший вес, чем урон за матч (масштабированный на 1/100).

---

## Шаг 4 — Нормализация к шкале 0–100

```
normalizedRating = (rawRating / MAX_RAW_RATING) × 100
```

### Почему MAX_RAW_RATING = 52.43?

52.43 выбрано с учётом реально достижимых высоких показателей игры. Потолок определяется
профилем исключительного теоретического игрока:

| Параметр | Значение |
|---|---|
| Матчей в год | 312 (6 карт/неделю × 52 недели) |
| Процент побед | 60% |
| Соотношение K/D | **3.2:1** |
| Средний урон за карту | **4 500** |

Расчёт:

```
avgModifier          = 0.6 × 1.1 + 0.4 × 0.9 = 1.02   (средний модификатор по всем матчам)

effectiveKdRatio     = 3.2 × 1.02 = 3.264              (убийства усилены модификатором, смерти — нет)
effectiveAvgDamage   = 4 500 × 1.02 = 4 590              (урон усилен модификатором за карту)

rawRating = 3.264 × 2 + 4 590 / 100 = 6.528 + 45.9 = 52.428 ≈ 52.43
```

Умножение на `1.02` отражает эффект модификатора победы: победы увеличивают убийства и урон на 1.1, поражения уменьшают на 0.9, и при 60% побед это усредняется до коэффициента 1.02. Сырые показатели потолочного игрока — **K/D 3.2:1** и **4 500 урона/карту** — после применения модификатора становятся 3.264 и 4 590.

Средний урон 4 500 за карту — это исключительный, редко достигаемый уровень игры,
значительно выше того, что показывают большинство сильных игроков (обычно 2 000–3 500/карту).
Это гарантирует, что шкала 0–100 остаётся содержательной во всём своём диапазоне.

Теоретический идеальный игрок набрал бы **≈99.9 из 100**. Для подстраховки
`finalRating` ограничивается максимумом **100** на случай крайних ситуаций.
Реальные игроки с хорошей стабильной игрой будут реалистично попадать в диапазон **30–70**.

```
finalRating = min(100, normalizedRating)
```

---

## Полная формула

```
if sessionHasWinner:
  modifier = won ? 1.1 : 0.9
else:
  modifier = 1.0                                           (нейтральная сессия: без бонуса/штрафа)

effectiveKills  = Σ kills  × modifier
effectiveDeaths = Σ deaths
effectiveDamage = Σ damage × modifier

kdRatio         = effectiveKills / effectiveDeaths
averageDamage   = effectiveDamage / totalMaps
rawRating       = kdRatio × 2 + averageDamage / 100
normalizedRating = (rawRating / 52.43) × 100

finalRating     = min(100, normalizedRating)              (0–100)
```
